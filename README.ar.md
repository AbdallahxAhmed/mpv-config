[English](README.md) | **العربية**

> حزمة موحّدة لإعداد مشغّل mpv ونشره وتنزيل الوسائط.

يحوّل `mpv-config` [mpv](https://mpv.io) إلى مشغّل وسائط فاخر جاهزٌ فور التثبيت، مع سكربتات Lua منتقاة، وشيدرات Anime4K لرفع دقة الأنمي، وفكّ تشفير عتادي متوافق مع كل منصة واجهة uosc تُستخدم بالفأرة، ومحرّك تنزيل مدمج يعتمد على yt-dlp وFFmpeg — ويُنشر كل ذلك عبر عمليات معاملات (Transactional) قابلة للاسترجاع بأمان.

## 📊 حالة المشروع

| | |
| --- | --- |
| الإصدار | **v1.0.0** (2026-10-07) — راجع [CHANGELOG.md](CHANGELOG.md) |
| واجهة الأوامر | `mpv-config` بأوامر `install` / `verify` / `update` / `rollback` / `status` / `sync-deps` / `download` / `uninstall` |
| الاختبارات | 465 اختبار Python و11 مجموعة اختبارات Lua على مصفوفة CI بثلاثة أنظمة تشغيل × Python 3.10–3.12، مع Ruff للفحص والتنسيق |
| المنصات | ويندوز 10/11، لينكس (X11 وKDE Wayland)، ماك أو إس |
| المتطلبات | ‏mpv ≥ 0.40 (يُحدَّث تلقائياً بواسطة المثبّت)، بايثون 3.10+ |

أحدث أعمال `main` (غير مُصدرة بعد في سجل التغييرات):

- **الكشف التلقائي عن الأنمي وشيدرات Anime4K بوضع A+A الافتراضي** — يتعرف سكربت `scripts/profile_picker.lua` تلقائياً ودون اتصال على ملفات الأنمي ويشغّل شيدرات Anime4K على وضع "A+A (Ultra Sharp)" فائق الحدة افتراضياً مع شارة تحقق واضحة على الشاشة (`Anime Detected: Anime4K [A+A] Active`). يمكن اختيار وضع آخر أثناء التثبيت (حيث يأتي A+A الخيار رقم 1 موصى به إلى جانب A وB وB+B وC وC+A وfast وoff) أو تغييره لاحقاً بثلاث طرق دائمة.
- **تحكم متكامل في سلاسة 144Hz وجودة العرض** — زر `F4` لتبديل سلاسة الحركة (144Hz Smooth مقابل التردد الأصلي Native Cadence)، و`Shift+F4` (أو `Alt+t`) للتبديل بين محددات الحركة الزمنية (`oversample` حاد بدون تغبيش مقابل `linear` ناعم ممزوج)، و`F10` لمعالج الشحذ الأصلي لمشغل mpv‏ (0.35 / إيقاف)، و`F3` لإزالة الشرائط اللونية النقية بمرور واحد دون توليد حبيبات صناعية.
- **سلاسة البث وشاشات 144Hz** — ترتيب أولوية برمجيات الترميز الحديثة (`format-sort=res,fps,codec:av01,codec:vp9.2,codec:vp9,vbr`) مفضلاً AV1 > VP9 > H.264 لتحقيق أقصى دقة وضوح ممكنة على 1080p مع استجابة تامة لواجهة وشريط المشغل عند 144Hz وتفادي تجمد التخزين المؤقت عبر `cache-pause=no`.
- **تطابق عتادي صامت للوحة المفاتيح العربية والإنجليزية** — على ويندوز، يوفّر مساعد AutoHotkey‏ (`tools/mpv_arabic_layout.ahk`) تطابقاً فيزيائياً 1:1 لرموز المفاتيح (Scan codes) للأحرف مثل `h` و`b` و`g` أثناء تشغيل التخطيط العربي، ويعمل بصمت تام 100% في الخلفية عبر واجهة Win32 الأصلية بـ `CREATE_NO_WINDOW` ويغلق تلقائياً بعد خروج mpv. وعلى لينكس وماك، توائم `input.conf` تغطي الحروف اللاتينية (`c→ؤ`، `a→ش`، `n→ى`، `?→؟`) مع مسارات Shift المباشرة (`أ/’/ٍ/آ/‘`) واختصارات `Ctrl+Shift`.
- **أوامر إدارة أكثر أماناً** — يقتصر `rollback` على نسخ هذا الإعداد الاحتياطية في مجلدات `mpv.backup.*` فقط؛ ويمكن لـ `uninstall` تنظيف الإعدادات والنسخ الاحتياطية والاعتماديات ومجلد التثبيت كلياً.
- **مثبّتات أكثر متانة** — ربط `install` و`verify` بمُنشر الإعدادات الحقيقي؛ وسكربت التثبيت يعمل مع أنظمة PEP 668 (مثل Ubuntu 24.04) عبر بيئة افتراضية خاصة.
- **نظافة أمنية** — لا تُتتبَّع مفاتيح خاصة ولا مسارات شخصية؛ ويفرض ذلك اختبار `tests/test_repo_hygiene.py`.

<a id="المميزات"></a>
## ✨ المميزات

<a id="جودة-التشغيل"></a>
### 🎬 جودة التشغيل
- **كشف تلقائي عن الأنمي مع وضع A+A الافتراضي** — يحدد سكربت `scripts/profile_picker.lua` تلقائياً ودون اتصال ما إذا كان الملف أنمي (عبر فرق الإصدار، مسار الصوت الياباني، علامات الحلقات، وسوم اللغات، أو عناوينك في `script-opts/anime_series.conf`). وعند الكشف، يفعّل شيدرات Anime4K على وضع **"A+A (Ultra Sharp)"** فائق الحدة افتراضياً مع شارة تحقق على الشاشة (`Anime Detected: Anime4K [A+A] Active`). وتبقى الأفلام الحية الواقعية وأفلام هوليوود على ملف `[live-action]` النقي بدون شيدرات.
- **اختيار وضع الشيدرات أثناء التثبيت** — يعرض المثبّت التفاعلي قائمة مرقّمة من **1 إلى 8** مع وصف قصير لكل وضع (تنقّل بسهمي `أعلى/أسفل` + `Enter`، والأرقام `1`–`8` للتحديد الفوري، و`Esc` لإبقاء الافتراضي)، حيث يبرز **A+A (Ultra Sharp)** كخيار رقم 1 موصى به إلى جانب `A` و`B` و`B+B` و`C` و`C+A` و`fast` و`off`؛ وتقبل التثبيتات غير التفاعلية خيار `--anime-preset <MODE>`.
- **تغيير الوضع الافتراضي وحفظه لاحقاً (3 طرق)**:
  1. *اختصارات المشغّل*: اضغط `Ctrl+1`..`Ctrl+6`، أو `Ctrl+0` (إلغاء)، أو `Ctrl+g` (تنقل دوري). يُطبَّق الاختيار فوراً ويُعرض على الشاشة (`(Saved as Default)`) ويُحفظ دائماً في `script-opts/anime4k.conf`.
  2. *ملف الإعدادات*: عدّل `script-opts/anime4k.conf` مباشرة (مثل `mode=A+A`).
  3. *سطر الأوامر*: شغّل `mpv-config update --anime-preset <MODE>` أو `python -m deploy.deployer --update --anime-preset <MODE>`.
- **أدوات تحكم متطورة للحركة والصورة لشاشات 144Hz**:
  - `F4`: تفعيل/تعطيل سلاسة الحركة (144Hz Smooth مقابل التردد الأصلي Native Cadence).
  - `Shift+F4` (أو `Alt+t`): التبديل بين محددات الحركة الزمنية (`oversample` حاد بدون تغبيش مقابل `linear` ناعم ممزوج).
  - `F10`: تفعيل/تعطيل معالج الشحذ الأصلي لمشغل mpv‏ (شحذ حاد 0.35 / إيقاف).
  - `F3`: تفعيل/تعطيل فلتر إزالة الشرائط اللونية النقي (Deband بمرور واحد مع 0 حبيبات اصطناعية).
- **لوحة مرجع سريع بضغطة زر** (`?` أو `F9`) — لوحة مرسومة بنواقل ASS فائقة الدقة تعرض المفاتيح وإجراءات الفأرة؛ وزر `/` بمفرده مُهمَل لتفادي خفض الصوت بالخطأ.
- سلاسل شيدرات **Anime4K v4.0.1** على المفاتيح `Ctrl+1`…`6` — تُطبَّق تلقائياً عبر ملف التعريف `[anime]` المكتشف آلياً (Anime4K + deband بمرتين)؛ ويبقى `[live-action]` نظيفاً بلا شيدرات افتراضياً، وتبقى `Ctrl+1`–`6` تجاوزاً يدوياً متاحاً لأي فيديو.
- محرك عرض **gpu-next (libplacebo)** مع كشف تلقائي للمنصة: ‏`d3d11` وفكّ شفرة غير منسوخ `d3d11va` على ويندوز (مقيس 1.4 مللي/إطار مقابل 5.3 مع `nvdec-copy`)، وVulkan مع `auto-safe` على لينكس، وVideoToolbox على ماك.
- **مزامنة عرض على تردد ثابت** — معايرة دقيقة لشاشات 1080p عند 144Hz؛ تطبيع خطي زمني يمتص نسب VSync غير الصحيحة دون اهتزاز، مع ملف تعريف استقرار خاص بـ KDE Wayland.
- **ملفات تعريف واعية بنوع المصدر** — `[anime]` (شيدرات Anime4K + منع الشرائط اللونية بمرتين)، `[live-action]` (تشغيل أصلي نقي)، والبث في `[protocol.https]` (ذاكرة 800MB وقراءة استباقية 60 ثانية مع نفس المحاذاة).
- **مسار عرض 10-بت كامل** — تحديد صريح لـ `dither-depth=10` (خيار `auto` في mpv يهبط بصمت إلى 8-بت على gpu-next)، وتبقيع مؤقت (Temporal dither)، وعتبات deband معايَرة.

<a id="الواجهة"></a>
### 🖥️ الواجهة
- **شريط أدوات uosc بالفأرة أولاً** — `القائمة · لصق | ترجمة · دبلجة · الجودة · تنزيل | صوت ثابت … ملء الشاشة`؛ لا حاجة للوحة المفاتيح (راجع [docs/YOUTUBE_GUI.md](docs/YOUTUBE_GUI.md)).
- معاينات مصغّرة من **thumbfast** عند المرور على شريط التقدم (مع ترقيعات محلية ضد حالات التسابق).
- **سجل المشاهدة والملفات الأخيرة** (memo) بزر `h`، وتبديل «صندوق خلفية الترجمة» بهيئة نتفليكس بـ `b` مع رسائل واضحة على الشاشة.
- قوائم التشغيل والإصدارات ومحددات الجودة تظهر حسب السياق؛ ويغلق إغلاق النافذة المشغّل فوراً.

<a id="يوتيوب-والبث"></a>
### 📺 يوتيوب والبث
- **أولوية برمجيات الترميز الحديثة وسلاسة 144Hz** — ضبط `ytdl-raw-options-append = format-sort=res,fps,codec:av01,codec:vp9.2,codec:vp9,vbr` لترتيب الأولوية AV1 > VP9 > H.264 لتحقيق أقصى وضوح على 1080p واستجابة فورية للواجهة والشريط عند 144Hz دون توقفات بفضل `cache-pause=no`.
- **خطّاف yt-dlp مخصص ومتين** — بثّ روابط يوتيوب والشبكة داخل المشغّل مع stub لـ yt-dlp يُحدَّث ذاتياً ودعم دلالات subprocess المتوافقة مع mpv 0.41+.
- **قائمة ترجمة عند الطلب** (`Ctrl+C` أو زر CC) بمجموعات *إنتاج المبدع / مولّدة آلياً / مترجمة آلياً*، مع تحميل غير متزامن قابل للإلغاء دون إعادة تحميل الفيديو.
- **ترشيح ذكي للدبلجات** — يحتفظ الخطّاف بأفضل إحالة صوتية لكل لغة/دور، ويختار مسار الفيديو الافتراضي بما يوافق الدبلجة المختارة.
- تكامل **SponsorBlock** مع تحديد المقاطع وإرسالها والتصويت إعجاباً/استياءً.
- **جودة افتراضية قابلة للضبط** — سقف جودة البث يعيش في ملف واحد (`script-opts/stream_quality.conf`، والافتراضي 1080p): اختره من المثبّت (`--stream-quality`)، أو تجاوزه لكل فيديو من زر Quality، أو استخدم خيار *"حفظ الجودة الحالية كافتراضية"* من القائمة نفسها — لا وجود لأي سقف صلب في الكود.

<a id="أدوات-المشغل"></a>
<a id="أدوات-المشغّل"></a>
### 🧰 أدوات المشغل
- **الصوت الثابت / الوضع الليلي** (`F8` أو زر شريط الأدوات) — سلسلة `dynaudnorm` مع `alimiter` ترفع صوت الحوار الهادئ دون ضخّ أو قصّ.
- **قائمة مزامنة الترجمة** (`n` عبر autosubsync مع `alass` الاختياري)، ولقطات شاشة مع/بدون ترجمة (`F1`/`F2` بصيغة PNG إلى `Pictures/mpv-screenshots`).
- **SmartSkip** (`>` `<` `?`) — تخطي ذكي للمقدمات/الختام/الصمت، وعدّادات تخطٍ تلقائي، وإضافة/حذف/حفظ الفصول.
- تقديم سريع هجين **evafast** بـ `Right`؛ وملء قائمة التشغيل تلقائياً من المجلد بـ `autoload`؛ وإيقاف تلقائي عند تصغير النافذة.
- **لصق للتشغيل** داخل المشغّل (`Ctrl+V`) — يطبّع مقاطع `youtu.be` و`watch?v=` و`shorts/…` والمسارات المقتبسة؛ ولا يُحوَّل الملف المحلي أبداً إلى رابط.

<a id="التنزيل"></a>
### ⬇️ التنزيل
- **محرّك تنزيل قائم على الإضافات**‏ (`BaseDownloader` ← `GenericDownloader`) يعمل بـ yt-dlp داخل العملية مع إعادة تعبئة عبر FFmpeg.
- **عامل تنزيل بـ 16 اتصالاً** (`tools/download_worker.py`) — عبر aria2c‏ (`-x16 -s16 -j16`) أو قطع متزامنة أصيلة.
- **مراقب الحافظة** ‏(`mpv-config download --watch`) الذي ينزّل كل رابط وسائط تنسخه مع استرداد تلقائي لكل رابط عند الخطأ.

<a id="أمان-النشر"></a>
### 🛡️ أمان النشر
- **نشر عبر معاملات** بمحرّك استرداد على نفس نظام الملفات، وسجل تدقيق ملكية الحزم، وتحقق للقراءة فقط (شملها فحص صياغة Lua).
- **نسخ احتياطية واسترجاع** — كل تغيير يلتقط لقطة للإعداد الحالي في `mpv.backup.*`؛ ويحافظ `update` على تخصيصاتك في `mpv.conf.user`.
- **إزالة نظيفة** مع خيارات `--purge-config` و`--remove-backups` و`--remove-deps` و`--remove-install-dir`.

<a id="دعم-التخطيط-العربي"></a>
### 🌍 دعم التخطيط العربي
- **تطابق عتادي فيزيائي على ويندوز**: يربط مساعد AutoHotkey‏ (`tools/mpv_arabic_layout.ahk`) رموز المفاتيح الفيزيائية مباشرة عند تركيز mpv أثناء تفعيل التخطيط العربي (`h` و`b` و`g` وغيرها)، ويعمل بصمت 100% في الخلفية بـ `CREATE_NO_WINDOW`.
- **توائم التخطيط عبر المنصات**: تُنشأ عند النشر في `input.conf` للأحرف اللاتينية (`c→ؤ`، `a→ش`، `n→ى`، `?→؟`) مع اختصارات Shift المباشرة (`أ/’/ٍ/آ/‘`) و`Ctrl+Shift` للأحرف الخمسة المرتبطة بمركّبات لا.

## ⌨️ اختصارات لوحة المفاتيح

المرجع السريع أدناه مرفق داخل `config/input.conf.template`؛ واختصارات SmartSkip الخاصة تعيش في `config/script-opts/SmartSkip.conf`.

<a id="سلاسل-شيدرات-anime4k-ctrl--رقم"></a>

### التوائم العربية (نفس المفتاح الفيزيائي)

يطابق مشغّل mpv الاختصارات بحسب **الحرف الناتج** عن تخطيط لوحة المفاتيح النشط في النظام وليس برمز المفتاح الفيزيائي (Scan code)، لذا عند تفعيل التخطيط العربي لا تستجيب اختصارات الأحرف اللاتينية المعتادة. لحل هذه المشكلة جذرياً:

1. **تطابق عتادي كامل على ويندوز (مساعد AutoHotkey)**:
   يُشغَّل مساعد `tools/mpv_arabic_layout.ahk` تلقائياً عند بدء mpv بواسطة سكربت `scripts/keyboard_layout.lua` عبر واجهة Win32 الأصلية بصمت تام 100% دون أي نوافذ كونسول (`CREATE_NO_WINDOW`)، ويلتقط رموز المفاتيح الفيزيائية مباشرة (مثل `SC023` للحرف H، و`SC030` للحرف B، و`SC022` للحرف G) حصرياً عند تنشيط نافذة mpv وتفعيل التخطيط العربي مع الحفاظ الكامل على مفاتيح التعديل (Shift/Ctrl/Alt)، ويغلق تلقائياً بعد ثانيتين من خروج المشغل (ويمكن إيقافه بـ `ahk=no` في `script-opts/keyboard_layout.conf`). لم يعد حارس لوحة المفاتيح بايثون القديم موجوداً إطلاقاً.

2. **توائم تخطيط مدمجة عبر المنصات (Linux وmacOS)**:
   يولّد مُنشر الإعدادات تلقائياً عند كل تثبيت أو تحديث كتلة توائم في نهاية ملف `input.conf` للأحرف اللاتينية القابلة للطباعة على تخطيط 101 العربي (`c→ؤ`، `a→ش`، `n→ى`، `?→؟`). ولتغطية مفاتيح مركبات لا الخمسة (`h g b G B`) التي تتشابه أحرفها الفردية، تتوفر مسارات Shift المباشرة (`Shift+H`→`أ`، `Shift+M`→`’`، `Shift+S`→`ٍ`، `Shift+B`→`آ`، `Shift+U`→`‘`) واختصارات `Ctrl+Shift` المتطابقة في كافة التخطيطات (`Ctrl+أ/’/ٍ/آ/‘`).

| المفتاح | المفتاح الفعلي | الوظيفة |
| --- | --- | --- |
| `ؤ` | C | قائمة الترجمات (توأم `c`) |
| `ش` | A | قائمة مسارات الصوت والدبلجات (توأم `a`) |
| `ى` | N | قائمة مزامنة الترجمة (توأم `n`) |
| `؟` | `?` | لوحة المرجع السريع (توأم `?`) |
| `Shift+H` / `Ctrl+Shift+H` | H | سجل المشاهدة / الملفات الأخيرة (memo) |
| `Shift+M` / `Ctrl+Shift+M` | M | تحديد مقطع SponsorBlock |
| `Shift+S` / `Ctrl+Shift+S` | S | إرسال مقطع SponsorBlock |
| `Shift+B` / `Ctrl+Shift+B` | B | تشغيل/إيقاف صندوق خلفية الترجمة |
| `Shift+U` / `Ctrl+Shift+U` | U | تصويت إيجابي SponsorBlock |
| `ز` | `.` | تشغيل/إيقاف التخطي التلقائي (نفس `Ctrl+.`) |
| `د` | `.` | تخطي الفئات (نفس `Alt+.`) |
| `غ` | Y | تأكيد عدّاد التخطي التلقائي |
| `ء` | X | إضافة فصل (نفس `Shift+N`) |
| `ق` | R | حذف الفصل (نفس `Alt+N`) |
| `ك` | `;` | حفظ الفصول (نفس `Ctrl+N`) |
| `؟` | `?` | تشغيل تخطي الصمت |

> التركيبات العربية المعدّلة `Ctrl`/`Alt`/`Shift` + حرف عربي لا يمكن بلوغها على ويندوز — تملك التوائم اللاتينية كل اختصارات التركيبات (`Ctrl+C`، `Ctrl+V`، `Ctrl+N`، …).

<a id="التثبيت"></a>
## 📦 التثبيت

ينشر `mpv-config` من نسخة مستودع محلية (المجلدات `deploy/` و`config/` و`scripts/` ليست جزءاً من الحزمة المثبتة)، لذا ثبّته بصيغة **قابلة للتحرير (editable)** من نسخة مكتملة. يمكن للأمر حينئذٍ العثور على النسخة من أي مجلد:

```bash
git clone https://github.com/AbdallahxAhmed/mpv-config.git
cd mpv-config

# تثبيت عالمي معزول عبر pipx (الموصى به)
pipx install --editable .

# أو داخل بيئة افتراضية
pip install --editable .
```

التثبيت العادي (غير القابل للتحرير) يعمل فقط إذا شغّلته من داخل النسخة، أو مع تعيين `MPV_CONFIG_REPO` لتشير إلى النسخة.

<a id="تثبيت-سريع-bootstrap"></a>
### تثبيت سريع (Bootstrap)

<a id="ويندوز-powershell"></a>
#### ويندوز (PowerShell)
```powershell
irm https://raw.githubusercontent.com/AbdallahxAhmed/mpv-config/main/install.ps1 | iex
```

<a id="لينكس--ماك"></a>
<a id="لينكس-ماك"></a>
#### لينكس / ماك
```bash
curl -fsSL https://raw.githubusercontent.com/AbdallahxAhmed/mpv-config/main/install.sh | bash
```

يثبّت السكربت واجهة الأوامر في بيئة افتراضية خاصة (`~/.local/share/mpv-config/venv`) ويربط `mpv-config` في `~/.local/bin`، لذا يعمل أيضاً على التوزيعات التي ترفض `pip install --user` (PEP 668، مثل Ubuntu 24.04). يحتاج بايثون 3.10+ (وعلى Debian/Ubuntu حزمة `python3-venv` أيضاً). ويمرّر الخيارات عبر `... | bash -s -- --dry-run`.

`mpv-config install` — الذي يشغّله كلا سكربتَي التثبيت السريع نيابة عنك — تفاعلي في الطرفية الحقيقية: يعرض قائمة مرقّمة (1–8) لسلاسل Anime4K التي سيستخدمها ملف التعريف `[anime]` المكتشف آلياً، مع **A+A (Ultra Sharp)** مميّزة كخيار رقم 1 موصى به. اضغط `Enter` لإبقاء الصف المميّز، أو تنقّل بسهمي `أعلى/أسفل`، أو اضغط `1`–`8` للتحديد الفوري، أو اضغط `Esc` لإبقاء الافتراضي. أما التشغيلات المُمرَّرة عبر أنبوب أو في CI فلا ترى هذه القائمة (يسري الافتراضي A+A المرفق)، وتمرير `--anime-preset <MODE>` يتخطاها.

<a id="الاستخدام"></a>
## 🚀 الاستخدام

يوفر `mpv-config` واجهة أوامر موحّدة:

<a id="1-تثبيت-ونشر-الإعدادات"></a>
### 1. تثبيت ونشر الإعدادات
ينشر الإعدادات والسكربتات والشيدرات المنتقاة إلى إعداد mpv المحلي:
```bash
mpv-config install
```

عاين أولاً باستخدام `mpv-config install --dry-run`؛ فلن يُنزَّل أو يُثبَّت أو يُستبدل أي شيء.

خيارات وقت النشر (تُمرَّر إلى المُنشر؛ شغّل `python -m deploy.deployer --help` للقائمة الكاملة):

| الخيار | الخيارات المتاحة (الافتراضي) | المعنى |
| --- | --- | --- |
| `--mpv-profile` | `windows-like` / `linux-like` / `native` (حسب النظام) | اختيار واجهة GPU وفكّ التشفير العتادي وVO |
| `--anime-preset` | `off` / `fast` / `A` / `A+A` / `B` / `B+B` / `C` / `C+A` ‏(`A+A`) | سلسلة شيدرات Anime4K المشغّلة لملف `[anime]` التلقائي (القائمة المرقّمة تُبرز A+A في التثبيت التفاعلي) |
| `--scaler-tier` | `light` / `balanced` / `quality` ‏(`balanced`) | درجة جودة `scale` / `cscale` / `dscale` |
| `--display-mode` | `auto` / `fixed` / `vrr` ‏(`fixed`) | نمط مزامنة العرض؛ `fixed` = مزامنة display-resample، و`vrr` اختياري لشاشات FreeSync/G-Sync |
| `--dither-depth` | `auto` / `8` / `10` ‏(`auto` يُحلَّل تلقائياً) | عمق التبقيع عند الإخراج |
| `--stream-quality` | `best` / `144` … `4320` ‏(`1080`) | سقف جودة البث الافتراضي يُزرع في `script-opts/stream_quality.conf` عند التثبيت الجديد فقط — الملف الموجود مسبقاً (اختيارك من قائمة Quality أو تعديلك اليدوي) محفوظ دائماً |
| `--mpv-version` | وسم إصدار | تثبيت وسم نسخة mpv على ويندوز (مثل `2026-05-15-4498c0ff81`) |

<a id="2-التحقق-من-التثبيت"></a>
### 2. التحقق من التثبيت
```bash
mpv-config verify
```

<a id="3-إدارة-النشر"></a>
### 3. إدارة النشر
```bash
mpv-config status             # إصدارات السكربتات/الشيدرات المثبتة وآخر جلسة مثبّت
mpv-config update             # تحديث السكربتات والشيدرات؛ إعداداتك محفوظة (مع دعم --anime-preset <MODE>)
mpv-config rollback           # استرجاع أحدث نسخة احتياطية (تُلتقط لقطة للإعداد الحالي أولاً)
mpv-config rollback <backup>  # استرجاع مجلد mpv.backup.* محدد من نسخ هذا الإعداد
mpv-config sync-deps          # تحديث yt-dlp وffmpeg وalass وffsubsync
mpv-config uninstall          # إزالة ما نُشر (تُؤخذ نسخة احتياطية أولاً)
```

الأوامر التي تغيّر شيئاً تقبل `--dry-run`. ولا يسترجع `rollback` سوى نسخة من نسخ الإعداد نفسه (مسار كامل أو اسم مجلد)، ويعرض المتاح إن ذكرت غير ذلك. ويزيل `uninstall --purge-config` مجلد الإعداد نفسه، و`--remove-backups` النسخ الاحتياطية، و`--remove-install-dir` نسخة `~/.mpv-config-deploy` مع البيئة الافتراضية الخاصة التي أنشأها `install.sh`.

<a id="4-تنزيل-الوسائط"></a>
### 4. تنزيل الوسائط
```bash
# تنزيل فيديو (الافتراضي ~/Downloads حتى 1080p)
mpv-config download "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# تحديد وجهة وسقف جودة مخصصين
mpv-config download "https://example.com/video" -o ~/Videos -q 720
```

وعلى ويندوز، يغلّف المشغّلان في جذر المستودع `Download-Video.cmd` و`Watch-Clipboard.cmd` الأوامر نفسها مع كونسول UTF-8.

<a id="5-مراقب-الحافظة-في-الخلفية"></a>
### 5. مراقب الحافظة في الخلفية
```bash
mpv-config download --watch
```

### اعتماديات النظام التي يديرها المثبت

‏mpv ≥ 0.40 (بناءات zhongfly اليومية على ويندوز مع بديل shinchiro، و`ppa:ubuntuhandbook1/mpv` على Ubuntu/Mint، ومستودعات x86-64-v3/v4 المحسّنة على CachyOS، وbrew/dnf/pacman في ما سوى)، و[yt-dlp](https://github.com/yt-dlp/yt-dlp) (ملف مستقل يُحافظ على حداثته)، وffmpeg، وffsubsync، وalass، وuv.

<a id="أدوات-المستودع"></a>
### أدوات المستودع

- **امتداد المتصفح MPV Companion** (`tools/extension/`، Chrome MV3) مع مضيف الرسائل الأصلية — تشغيل بنقرة واحدة ومزامنة كوكيز الموقع إلى mpv/yt-dlp لمواقع Cloudflare المحمية، مع دعم FlareSolverr اختياري (`tools/core/flaresolverr.py`). سجّله عبر `tools/register_extension.py`.
- **`tools/download_worker.py`** — عامل تنزيل بدون واجهة بـ 16 اتصالاً (aria2c أو قطع متزامنة أصيلة).
- **`tools/vtt_translate.py`** — ترجمة ترجمات WebVTT (إلى العربية مثلاً) دون كوكيز أو مفاتيح API.
- **`tools/apply_youtube_gui.py`** — ترقية مستقلة بتخطيط شريط الأدوات لـ uosc مع معاينة أولاً.

<a id="التطوير"></a>
## 🛠️ التطوير

<a id="تجهيز-بيئة-التطوير"></a>
### تجهيز بيئة التطوير
```bash
# استنساخ المستودع
git clone https://github.com/AbdallahxAhmed/mpv-config.git
cd mpv-config

# تثبيت قابل للتحرير مع اعتماديات التطوير
pip install -e .
pip install -r requirements-dev.txt

# تثبيت خطافات git المسبقة
pre-commit install
```

<a id="تشغيل-الاختبارات-وفحوصات-الجودة"></a>
### تشغيل الاختبارات وفحوصات الجودة
```bash
# تشغيل مجموعة اختبارات الوحدات
python -m unittest discover -s tests

# تشغيل اختبارات سكربتات Lua
python tests/run_lua_tests.py

# الفحص والتنسيق
ruff check .
ruff format .
```
