> حزمة موحّدة لإعداد مشغّل mpv ونشره وتنزيل الوسائط.

يحوّل `mpv-config` [mpv](https://mpv.io) إلى مشغّل وسائط فاخر جاهزٌ فور التثبيت، مع سكربتات Lua منتقاة، وشيدرات Anime4K لرفع دقة الأنمي، وفكّ تشفير عتادي متوافق مع كل منصة واجهة uosc تُستخدم بالفأرة، ومحرّك تنزيل مدمج يعتمد على yt-dlp وFFmpeg — ويُنشر كل ذلك عبر عمليات معاملات (Transactional) قابلة للاسترجاع بأمان.

أحدث أعمال `main` (غير مُصدرة بعد في سجل التغييرات):

- **إصلاحات تزامن العرض أثناء التشغيل** — استخدام `tscale=linear` مع `video-timing-offset=0.01` لتشغيل بلا اهتزاز عند مزامنة `display-resample` على شاشات 144Hz ثابتة، وملف تعريف استقرار معدل التحديث مخصص لـ KDE Wayland فقط.
- **اختصارات عربية بلا تعارض (تخطيط AZERTY 102)** — مجرّبة على تخطيط لوحة المفاتيح الفعلي ومفحوصة ضد التعارضات عبر `tests/test_keybinding_conflicts.py`.
- **أوامر إدارة أكثر أماناً** — يقتصر `rollback` على نسخ هذا الإعداد الاحتياطية في مجلدات `mpv.backup.*` فقط؛ ويمكن لـ `uninstall` تنظيف الإعدادات والنسخ الاحتياطية والاعتماديات ومجلد التثبيت كلياً.
- **مثبّتات أكثر متانة** — ربط `install` و`verify` بمُنشر الإعدادات الحقيقي؛ وسكربت التثبيت يعمل مع أنظمة PEP 668 (مثل Ubuntu 24.04) عبر بيئة افتراضية خاصة.
- **نظافة أمنية** — لا تُتتبَّع مفاتيح خاصة ولا مسارات شخصية؛ ويفرض ذلك اختبار `tests/test_repo_hygiene.py`.

## ✨ المميزات

### 🎬 جودة التشغيل
- سلاسل شيدرات **Anime4K v4.0.1** على المفاتيح `Ctrl+1`…`6`، مع ملف تعريف `[anime]` يُطبَّق تلقائياً على الملفات التي يحتوي مسارها على `anime` أو `cartoon`.
- محرك عرض **gpu-next (libplacebo)** مع كشف تلقائي للمنصة: ‏`d3d11` وفكّ شفرة غير منسوخ `d3d11va` على ويندوز (مقيس 1.4 مللي/إطار مقابل 5.3 مع `nvdec-copy`)، وVulkan مع `auto-safe` على لينكس، وVideoToolbox على ماك.
- **مزامنة عرض على تردد ثابت** — معايرة دقيقة لشاشات 1080p عند 144Hz؛ تطبيع خطي زمني يمتص نسب VSync غير الصحيحة دون اهتزاز، مع ملف تعريف استقرار خاص بـ KDE Wayland.
- **ملفات تعريف واعية بنوع المصدر** — `[anime]` (شيدرات Anime4K + منع الشرائط اللونية بمرتين)، `[live-action]` (deband خفيف بمرور واحد مع حبيبات)، والبث في `[protocol.https]` (ذاكرة 800MB وقراءة استباقية 60 ثانية مع نفس المحاذاة).
- **مسار عرض 10-بت كامل** — تحديد صريح لـ `dither-depth=10` (خيار `auto` في mpv يهبط بصمت إلى 8-بت على gpu-next)، وتبقيع مؤقت (Temporal dither)، وعتبات deband معايَرة.

### 🖥️ الواجهة
- **شريط أدوات uosc بالفأرة أولاً** — `القائمة · لصق | ترجمة · دبلجة · الجودة · تنزيل | صوت ثابت … ملء الشاشة`؛ لا حاجة للوحة المفاتيح (راجع [docs/YOUTUBE_GUI.md](docs/YOUTUBE_GUI.md)).
- معاينات مصغّرة من **thumbfast** عند المرور على شريط التقدم (مع ترقيعات محلية ضد حالات التسابق).
- **سجل المشاهدة والملفات الأخيرة** (memo) بزر `h`، وتبديل «صندوق خلفية الترجمة» بهيئة نتفليكس بـ `b` مع رسائل واضحة على الشاشة.
- قوائم التشغيل والإصدارات ومحددات الجودة تظهر حسب السياق؛ ويغلق إغلاق النافذة المشغّل فوراً.

### 📺 يوتيوب والبث
- **خطّاف yt-dlp مخصص ومتين** — بثّ روابط يوتيوب والشبكة داخل المشغّل مع stub لـ yt-dlp يُحدَّث ذاتياً ودعم دلالات subprocess المتوافقة مع mpv 0.41+.
- **قائمة ترجمة عند الطلب** (`Ctrl+C` أو زر CC) بمجموعات *إنتاج المبدع / مولّدة آلياً / مترجمة آلياً*، مع تحميل غير متزامن قابل للإلغاء دون إعادة تحميل الفيديو.
- **ترشيح ذكي للدبلجات** — يحتفظ الخطّاف بأفضل إحالة صوتية لكل لغة/دور، ويختار مسار الفيديو الافتراضي بما يوافق الدبلجة المختارة.
- تكامل **SponsorBlock** مع تحديد المقاطع وإرسالها والتصويت إعجاباً/استياءً.
- سقف 1080p لصيغ البث والتنزيل على السواء (`format-sort=res:1080,vbr,abr`).

### 🧰 أدوات المشغّل
- **الصوت الثابت / الوضع الليلي** (`F8` أو زر شريط الأدوات) — سلسلة `dynaudnorm` مع `alimiter` ترفع صوت الحوار الهادئ دون ضخّ أو قصّ.
- **قائمة مزامنة الترجمة** (`n` عبر autosubsync مع `alass` الاختياري)، ولقطات شاشة مع/بدون ترجمة (`F1`/`F2` بصيغة PNG إلى `Pictures/mpv-screenshots`).
- **SmartSkip** (`>` `<` `?`) — تخطي ذكي للمقدمات/الختام/الصمت، وعدّادات تخطٍ تلقائي، وإضافة/حذف/حفظ الفصول.
- تقديم سريع هجين **evafast** بـ `Right`؛ وملء قائمة التشغيل تلقائياً من المجلد بـ `autoload`؛ وإيقاف تلقائي عند تصغير النافذة.
- **لصق للتشغيل** داخل المشغّل (`Ctrl+V`) — يطبّع مقاطع `youtu.be` و`watch?v=` و`shorts/…` والمسارات المقتبسة؛ ولا يُحوَّل الملف المحلي أبداً إلى رابط.

### ⬇️ التنزيل
- **محرّك تنزيل قائم على الإضافات**‏ (`BaseDownloader` ← `GenericDownloader`) يعمل بـ yt-dlp داخل العملية مع إعادة تعبئة عبر FFmpeg.
- **عامل تنزيل بـ 16 اتصالاً** (`tools/download_worker.py`) — عبر aria2c‏ (`-x16 -s16 -j16`) أو قطع متزامنة أصيلة.
- **مراقب الحافظة** ‏(`mpv-config download --watch`) الذي ينزّل كل رابط وسائط تنسخه مع استرداد تلقائي لكل رابط عند الخطأ.

### 🛡️ أمان النشر
- **نشر عبر معاملات** بمحرّك استرداد على نفس نظام الملفات، وسجل تدقيق ملكية الحزم، وتحقق للقراءة فقط (شملها فحص صياغة Lua).
- **نسخ احتياطية واسترجاع** — كل تغيير يلتقط لقطة للإعداد الحالي في `mpv.backup.*`؛ ويحافظ `update` على تخصيصاتك في `mpv.conf.user`.
- **إزالة نظيفة** مع خيارات `--purge-config` و`--remove-backups` و`--remove-deps` و`--remove-install-dir`.

### 🌍 دعم التخطيط العربي
- اختصارات توأم ثنائية اللغة لتخطيط AZERTY 102 العربي، مُستقصاة من تخطيط لوحة المفاتيح المثبَّت ومفحوصة كي لا يتحرك أي اختصار خطأً بسبب مركّبات «لا» (راجع جداول الاختصارات أدناه).

### التوأم العربية (AZERTY 102)

الحقيقة الأساسية باختصار من التخطيط المثبّت (`00000C01`): ‏`b→لا`، `f→ب`، `j→ت`، `l→م`، `p→ح`، `a→ش`، `c→ؤ`، `n→ى`، `y→غ`، `x→ء`، `r→ق`، `;→ك`. ولا يمكن لـ mpv ربط سوى نقاط ترميز منفردة، لذا لا يمكن ربط المركّب «لا» أبداً — تُترك تلك الحروف دون ربط عن قصد، وتتسكن كل التوائم على حروف آمنة:

| المفتاح | المفتاح الفعلي | الوظيفة |
| --- | --- | --- |
| `ؤ` | C | قائمة الترجمات |
| `ش` | A | قائمة الصوت والدبلجات |
| `ح` | P | سجل المشاهدة (memo) |
| `ى` | N | مزامنة الترجمة |
| `ب` | F | مفتاح خلفية الترجمة |
| `ت` | J | تحديد مقطع SponsorBlock |
| `م` | L | إرسال مقطع SponsorBlock |
| `ز` | `.` | تشغيل/إيقاف التخطي التلقائي (نفس `Ctrl+.`) |
| `د` | `.` | تخطي الفئات (نفس `Alt+.`) |
| `غ` | Y | تأكيد عدّاد التخطي التلقائي |
| `ء` | X | إضافة فصل (نفس `Shift+N`) |
| `ق` | R | حذف الفصل (نفس `Alt+N`) |
| `ك` | `;` | حفظ الفصول (نفس `Ctrl+N`) |
| `؟` | `?` | تشغيل تخطي الصمت |

> التركيبات العربية المعدّلة `Ctrl`/`Alt`/`Shift` + حرف عربي لا يمكن بلوغها على ويندوز — تملك التوائم اللاتينية كل اختصارات التركيبات (`Ctrl+C`، `Ctrl+V`، `Ctrl+N`، …).

## 📦 التثبيت

ينشر `mpv-config` من نسخة مستودع محلية (المجلدات `deploy/` و`config/` و`scripts/` ليست جزءاً من الحزمة المثبتة)، لذا ثبّته بصيغة **قابلة للتحرير (editable)** من نسخة مكتملة. يمكن للأمر حينئذٍ العثور على النسخة من أي مجلد:

```bash
git clone https://github.com/AbdallahxAhmed/mpv-config.git
cd mpv-config

# تثبيت عالمي معزول عبر pipx (الموصى به)
pipx install --editable .

# أو داخل بيئة افتراضية
pip install --editable .
```

التثبيت العادي (غير القابل للتحرير) يعمل فقط إذا شغّلته من داخل النسخة، أو مع تعيين `MPV_CONFIG_REPO` لتشير إلى النسخة.

### تثبيت سريع (Bootstrap)

#### ويندوز (PowerShell)
```powershell
irm https://raw.githubusercontent.com/AbdallahxAhmed/mpv-config/main/install.ps1 | iex
```

#### لينكس / ماك
```bash
curl -fsSL https://raw.githubusercontent.com/AbdallahxAhmed/mpv-config/main/install.sh | bash
```

يثبّت السكربت واجهة الأوامر في بيئة افتراضية خاصة (`~/.local/share/mpv-config/venv`) ويربط `mpv-config` في `~/.local/bin`، لذا يعمل أيضاً على التوزيعات التي ترفض `pip install --user` (PEP 668، مثل Ubuntu 24.04). يحتاج بايثون 3.10+ (وعلى Debian/Ubuntu حزمة `python3-venv` أيضاً). ويمرّر الخيارات عبر `... | bash -s -- --dry-run`.

## 🚀 الاستخدام

يوفر `mpv-config` واجهة أوامر موحّدة:

### 1. تثبيت ونشر الإعدادات
ينشر الإعدادات والسكربتات والشيدرات المنتقاة إلى إعداد mpv المحلي:
```bash
mpv-config install
```

عاين أولاً باستخدام `mpv-config install --dry-run`؛ فلن يُنزَّل أو يُثبَّت أو يُستبدل أي شيء.

خيارات وقت النشر (تُمرَّر إلى المُنشر؛ شغّل `python -m deploy.deployer --help` للقائمة الكاملة):

| الخيار | الخيارات المتاحة (الافتراضي) | المعنى |
| --- | --- | --- |
| `--mpv-profile` | `windows-like` / `linux-like` / `native` (حسب النظام) | اختيار واجهة GPU وفكّ التشفير العتادي وVO |
| `--anime-preset` | `off` / `fast` / `A` / `A+A` / `B` / `C` ‏(`A`) | سلسلة Anime4K التي يستخدمها ملف التعريف `[anime]` التلقائي |
| `--scaler-tier` | `light` / `balanced` / `quality` ‏(`balanced`) | درجة جودة `scale` / `cscale` / `dscale` |
| `--display-mode` | `auto` / `fixed` / `vrr` ‏(`fixed`) | نمط مزامنة العرض؛ `fixed` = مزامنة display-resample، و`vrr` اختياري لشاشات FreeSync/G-Sync |
| `--dither-depth` | `auto` / `8` / `10` ‏(`auto` يُحلَّل تلقائياً) | عمق التبقيع عند الإخراج |
| `--mpv-version` | وسم إصدار | تثبيت وسم نسخة mpv على ويندوز (مثل `2026-05-15-4498c0ff81`) |

### 2. التحقق من التثبيت
```bash
mpv-config verify
```

### 3. إدارة النشر
```bash
mpv-config status             # إصدارات السكربتات/الشيدرات المثبتة وآخر جلسة مثبّت
mpv-config update             # تحديث السكربتات والشيدرات؛ إعداداتك الشخصية محفوظة
mpv-config rollback           # استرجاع أحدث نسخة احتياطية (تُلتقط لقطة للإعداد الحالي أولاً)
mpv-config rollback <backup>  # استرجاع مجلد mpv.backup.* محدد من نسخ هذا الإعداد
mpv-config sync-deps          # تحديث yt-dlp وffmpeg وalass وffsubsync
mpv-config uninstall          # إزالة ما نُشر (تُؤخذ نسخة احتياطية أولاً)
```

الأوامر التي تغيّر شيئاً تقبل `--dry-run`. ولا يسترجع `rollback` سوى نسخة من نسخ الإعداد نفسه (مسار كامل أو اسم مجلد)، ويعرض المتاح إن ذكرت غير ذلك. ويزيل `uninstall --purge-config` مجلد الإعداد نفسه، و`--remove-backups` النسخ الاحتياطية، و`--remove-install-dir` نسخة `~/.mpv-config-deploy` مع البيئة الافتراضية الخاصة التي أنشأها `install.sh`.

### 4. تنزيل الوسائط
```bash
# تنزيل فيديو (الافتراضي ~/Downloads حتى 1080p)
mpv-config download "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# تحديد وجهة وسقف جودة مخصصين
mpv-config download "https://example.com/video" -o ~/Videos -q 720
```

وعلى ويندوز، يغلّف المشغّلان في جذر المستودع `Download-Video.cmd` و`Watch-Clipboard.cmd` الأوامر نفسها مع كونسول UTF-8.

### 5. مراقب الحافظة في الخلفية
```bash
mpv-config download --watch
```

### اعتماديات النظام التي يديرها المثبّت

‏mpv ≥ 0.40 (بناءات zhongfly اليومية على ويندوز مع بديل shinchiro، و`ppa:ubuntuhandbook1/mpv` على Ubuntu/Mint، ومستودعات x86-64-v3/v4 المحسّنة على CachyOS، وbrew/dnf/pacman في ما سوى)، و[yt-dlp](https://github.com/yt-dlp/yt-dlp) (ملف مستقل يُحافظ على حداثته)، وffmpeg، وffsubsync، وalass، وuv.

### أدوات المستودع

- **امتداد المتصفح MPV Companion** (`tools/extension/`، Chrome MV3) مع مضيف الرسائل الأصلية — تشغيل بنقرة واحدة ومزامنة كوكيز الموقع إلى mpv/yt-dlp لمواقع Cloudflare المحمية، مع دعم FlareSolverr اختياري (`tools/core/flaresolverr.py`). سجّله عبر `tools/register_extension.py`.
- **`tools/download_worker.py`** — عامل تنزيل بدون واجهة بـ 16 اتصالاً (aria2c أو قطع متزامنة أصيلة).
- **`tools/vtt_translate.py`** — ترجمة ترجمات WebVTT (إلى العربية مثلاً) دون كوكيز أو مفاتيح API.
- **`tools/apply_youtube_gui.py`** — ترقية مستقلة بتخطيط شريط الأدوات لـ uosc مع معاينة أولاً.
